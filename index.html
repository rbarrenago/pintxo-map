METHODOLOGY & GOVERNANCE

About this experiment

The ingredient attributes, rules, simulated panel and initial balance scores are illustrative. Recipe combinations are enumerated from an example catalog; the learning-based archive can change the representative candidate in each map cell.

Simulation and manual tasting use separate preference histories. Manual comparisons are stored only in this browser session and can be exported without names. No data is sent to a server by this application.

GOe has not validated or endorsed this demo. Professional sensory protocols, food-safety review, informed consent and secure data management would be prerequisites for an actual research pilot.
